# Ollama 聊天室

跟 `file_search` 專案完全獨立的小工具：用本機 Ollama 做一個像 ChatGPT 的網頁聊天視窗，支援文字對話、串流回應、上傳圖片（需模型支援看圖）、上傳文件（pdf/docx/txt/md…會先抽出文字再送進對話）。

## 執行

雙擊 `啟動-Ollama聊天室.bat`（或桌面上它自己建立的「Ollama 聊天室」捷徑）：
第一次會自動 `pip install` 相依套件、在桌面建立/更新捷徑，然後問你要不要
開公網（ngrok，y/N）。**區網永遠開著**（其他裝置用你的區網 IP 就能連），
公網是額外選項。第一次開公網（或任何時候）都會要求設一組共用密碼；密碼
可以選擇存到 `share-config.txt`（純本機檔案，下次啟動不用再輸入）。

單純本機用、不想要任何分享/密碼機制，直接手動跑：

```
pip install -r requirements.txt
python server.py
```

開瀏覽器到 <http://localhost:8795/ollama/>——這樣跑完全沒有密碼、只收本機
連線，跟以前一樣。**網站掛在 `/ollama` 路徑下，不是網域根目錄**（方便同一個
ngrok 網域之後想再加別的服務），開 `http://localhost:8795/` 會自動轉過去。

## 設定

- 預設連本機 Ollama（`http://localhost:11434`）。要接區網/其他位址，啟動前設環境變數：
  `set OLLAMA_BASE_URL=http://192.168.1.50:11434`
- 想換 port：`set OLLAMA_CHAT_PORT=8888`
- 對話歷史只存在瀏覽器 `localStorage`（純前端，重整頁面不會消失，換瀏覽器/清快取就沒了），伺服器完全不落地保存任何對話內容。
- 圖片：只有模型支援看圖（`/api/show` 的 `capabilities` 有 `vision`）才能送出，下拉選單裡模型名稱後面有 👁 標記的才支援；選到不支援的模型時，附加的圖片會被忽略並提示。
- 文件：伺服器把上傳的檔案在本機抽成純文字（pdf 用 `pypdf`、docx 用 `python-docx`、其他當純文字讀），超過 1.2 萬字元會截斷（見「回應變慢／卡住」那段的教訓），抽出的文字附加在你下一則訊息後面一起送出，跟真正上傳/儲存檔案無關，用完即丟。
- 文件的圖片：**pdf／docx 額外會抽圖片給支援看圖的模型用**——pdf 用 `pymupdf` 把前 6 頁整頁渲染成圖（掃描版 PDF 沒有文字層，純文字抽取讀不到內容，只有這條路徑看得到）；docx 直接從裡面嵌入的圖片（`word/media/`）抓前 6 張。抓到的圖片會併入附加圖片清單，跟手動貼圖一樣受「目前模型支不支援看圖」那個判斷（見上面「圖片」那條）——選到純文字模型就不會送出，只是純粹不使用而已。純文字格式（txt/json/csv/md/log…）沒有版面可言，不會做這一步。圖片會縮到寬度 ≤1280px、轉 JPEG（品質 78）避免請求太肥。

## 區網／公網分享

跟 `file_search` 那幾面牆同一套精神，機制簡化過（這個專案沒有多人身分／
PIN／每日額度那套，只有單一共用密碼）：

- `SHARE_MODE=lan` 時 Flask 改綁 `0.0.0.0`（區網其他裝置連得到），沒設就
  只收 `127.0.0.1`（純本機，跟以前行為一樣）。`.bat` 每次啟動都會設這個。
- `SHARE_TOKEN` 有設的話，**本機自己永遠不用密碼**（用 `remote_addr` 是不是
  loopback 判斷），區網/公網的人第一次連會看到密碼頁，密碼對了就用
  session cookie 記住（重開 server 會全部重新要求輸入，是刻意設計）。
- **公網判斷有一個坑，已經處理**：ngrok 的 agent 也是跑在你這台機器上、
  再轉發到本機 port，所以公網進來的請求在 Flask 眼中 `remote_addr` 一樣是
  `127.0.0.1`——單看 IP 會把「網路上的陌生人」誤判成你自己。實際判斷法是
  「loopback IP **且沒有** `X-Forwarded-For` 標頭」（ngrok/任何反向代理都
  會加這個標頭），這個跟 `file_search` 那幾面牆踩過的同一個坑、同一套解法。
- 想不透過 `.bat` 手動測：
  `set SHARE_MODE=lan`、`set SHARE_TOKEN=你的密碼`、`set SHARE_PUBLIC=on`
  （要不要開 ngrok）、`set OLLAMA_CHAT_PORT=8795`，再 `python server.py`。
- 分享出去的人能無限制呼叫你本機的 Ollama（沒有 `file_search` 那套每日額度
  限制），公網分享前請自行評估你想開放給誰、開多久。
