# 桌面牆「產品展示」腳本

用**真實的滑鼠與鍵盤**把桌面牆的主要功能完整走一遍，約 4 分鐘（38 步），給人看「桌面版能做什麼」。
每一步在螢幕下方正中央的**字幕條**說明正在展示的功能（「段落 · 第幾步 / 共幾步」＋標題＋一句說明），截圖也會拍進去。

```
桌面牆外殼：右下角控制列——穿透／互動模式、隱藏／顯示整面牆
便利貼牆  ：新增（分類標籤、填空欄、待辦清單）→ 在牆上勾待辦（完成章）→ 釘選 → 即時搜尋 → 分類篩選
            → 淺／深色主題 → 拉框裁切 → 拖出去懸浮（已有 5 則以上時改展示上限提醒）→ 刪除 → 從垃圾桶復原 → 批次新增
            → 從 JSON 匯入範例資料（各分類）→ AI 搜尋（模擬回答）→ 批次刪除一個分類 → 匯出 HTML 並打開來看
設定視窗  ：Shift+V 開啟 → 牆面透明度即時預覽 → 試聽到期鬧鐘
索引牆    ：Shift+C 切換 → 新增索引集 → 匯入資料夾（掃描：類別分佈／副檔名統計、依類型篩選重掃）
            → 批次分類（建議來源：上層資料夾／檔案類型）→ 批次補說明（擷取內容，不用 AI）→ 預覽檔案內容
            → 手動改說明與分類 → 文件檢視 → 分組檢視
            → 搜尋＋預覽影片 → 變成懸浮視窗 → 拖拉邊界放大 → 播放 N 秒後停止 → 按右上角 ✕ 結束程式
```

**展示素材**：沒給 `-ImportDir` 時，腳本把 `file_search\功能展示用文件\`（`-DocsDir` 可換；各種類型的小檔案：
mp3／jpg／docx／pptx／zip／json／py／h／txt）放在暫放資料夾最上層，`media\cat-demo.mp4` 放在子資料夾 `影片\`——
兩層才看得出「依上層資料夾分類」的差別；純文字類（py／h／json／txt）讓「批次補說明」擷取得到內容。
暫放在 `%USERPROFILE%\Documents\桌面牆展示素材`，清理成功後刪掉。**換裝置要能跑，`功能展示用文件\` 也要進 git。**

**右側常駐說明「你的原始檔案：唯讀」**（`lib.ps1` 的 `DemoNotice`，跟字幕條同一種滑鼠穿透視窗）：這是對使用者的承諾，
2026-10 寫上去之前查過 files-web／notes-web 後端所有寫檔、刪檔、改名的地方——只動 `indexes\` 底下系統自己的資料
（索引 .md、便利貼 JSON、歷史快照、插圖複本、上傳區），從不碰索引指向的原檔案。**之後若加了會動原檔案的功能，這段文字要跟著改。**

**AI 搜尋用模擬回答**：那一步在網頁裡暫時攔下 `/api/ai/search` 這一支請求、回預先寫好的答案（依範例資料的「旅行」分類），
其他請求照常；字幕和回答本身都註明「沒有實際呼叫 AI」，示範完立刻還原。

**範例資料與暫存檔**：「從 JSON 匯入」用腳本當場產生的範例便利貼（工作／學習／購物／旅行／健康，11 則），id 一律
`demo-import-` 開頭，清理時用 `--id-prefix` 精確刪除（主清單＋垃圾桶）。匯入的 JSON 與匯出的 HTML 放在
`C:\Users\Public\desktop-wall-demo-*`——系統檔案對話框要打完整路徑，**路徑必須是純英數**（中文會被輸入法攔截），結束時刪掉。
批次刪除**只勾範例資料的那兩則**（標題完全比對、刪除前再核對勾選清單），不用「勾選目前顯示」，免得勾到使用者自己的便利貼。
匯出的 HTML 在桌面牆自己開的視窗裡打開（先把牆收起來），看完關掉——不動使用者的瀏覽器。

**刻意不展示**：AI 生成便利貼、批次補說明的「用 AI 產生」：要打外部 API，會花錢、結果每次不同，不適合重播。
匯出 JSON 備份、共用模式（要另外開 server）也不在流程裡。

**字幕條**是 `lib.ps1` 的 `DemoCaption`——獨立的 Win32 視窗，不是畫在牆的網頁裡（牆會切穿透、隱藏、裁切、換成索引牆，
網頁內的元素撐不過這些）。滑鼠穿透＋不搶焦點，不影響腳本的真實滑鼠鍵盤操作；每 300ms 重新宣告最上層，不會被桌面牆蓋掉。
總步數是 `run.ps1` 自己數「行首的 `Step '` 呼叫」有幾個——**每一步只寫一個 Step 呼叫，不要放在 if/else 兩邊**，不然會多算。

## 只看某些片段、調速度、提前結束

| 想要 | 怎麼做 |
|---|---|
| 只看某幾段 | 雙擊批次檔會先問（輸入編號，可多選）；或 `-Sections shell,sticky,settings,index` 挑著寫 |
| 慢一點／快一點 | 批次檔選單選 慢／正常／快；或 `-Speed 0.7`（慢）、`-Speed 1.6`（快）。**展示中**按 **F7 放慢、F9 加快** |
| 暫停一下 | **F8** 暫停／繼續（暫停時可以自由動滑鼠，不會被當成要結束） |
| 提前結束 | **F12**，或**動一下滑鼠**——一樣會關掉桌面牆、清掉展示資料、還原設定；結束碼 2，批次檔顯示「已提前結束」 |

四段：`shell` 桌面牆外殼（約 20 秒）、`sticky` 便利貼牆（約 115 秒）、`settings` 設定視窗（約 15 秒）、`index` 索引牆（約 100 秒）；
開場與結束清理一定會跑。各段互不依賴（沒看 `shell` 而牆用穿透模式啟動時，會先不出聲地切成互動模式）。
字幕條右上角常駐這些按鍵提示與目前速度；「第幾步／共幾步」只算選到的段落（腳本用 `#@section 名稱` 標記切段來數）。
速度只縮放「讓觀眾閱讀的停頓」（`Hold`／`Step`），滑鼠移動、打字維持人的節奏。

**偵測方式**（`lib.ps1` 的 `DemoKeys`）：背景執行緒每 10ms 看一次 F7／F8／F9／F12 與游標位置。按鍵「記下按過幾次」，
主迴圈有空再取走——直接在 PowerShell 主迴圈輪詢會漏掉短按（實測漏過）。腳本移動游標一律走 `DemoKeys::MoveTo`
（先記預期位置再移），游標偏離預期位置 40px 以上＝有人在動滑鼠；同時接受上一個預期位置，避免剛移動的瞬間誤判。
這幾個鍵展示本身都不會按，不會誤觸。

## 用法

**最簡單：雙擊專案根目錄的 `啟動-桌面牆自動化展示.bat`**（顯示提醒、倒數 5 秒後開始；後面接的參數會原封不動傳給 `run.ps1`，
例如 `啟動-桌面牆自動化展示.bat -PlaySeconds 3 -NoCleanup`；設環境變數 `DEMO_NOWAIT=1` 可略過倒數與結尾的暫停）。
批次檔要存成 **UTF-8 無 BOM ＋ CRLF**（BOM 會讓 cmd 讀壞第一行），中文訊息要放在 `chcp 65001` 之後。

或直接呼叫 PowerShell：

```powershell
# 用預設參數（貓咪自拍影片資料夾、播 4 秒）
powershell -ExecutionPolicy Bypass -File wallpaper-app\demo\run.ps1

# 換素材／秒數／保留資料
powershell -ExecutionPolicy Bypass -File wallpaper-app\demo\run.ps1 `
  -ImportDir "$env:USERPROFILE\Downloads\3d遊戲資源" -VideoFile '不穩定碎片集合體.mp4' `
  -PlaySeconds 3 -IndexName '3d遊戲資源' -NoCleanup
```

| 參數 | 預設 | 說明 |
|---|---|---|
| `-ImportDir` | （空） | 要匯入的資料夾。**必須在 下載／文件／家目錄 底下**（檔案瀏覽器的捷徑），腳本從最近的捷徑一層層點進去。不給就把 `-DocsDir` 的文件＋`media\` 的影片組成展示素材（見上面「展示素材」），複製到 `%USERPROFILE%\Documents\桌面牆展示素材` 暫放，清理成功後刪掉（`-NoCleanup` 時保留） |
| `-DocsDir` | `file_search\功能展示用文件` | 展示用的各類型文件（給掃描、批次分類、批次補說明用）。只在沒給 `-ImportDir` 時使用 |
| `-VideoFile` | `cat-demo.mp4` | 要預覽、懸浮、播放的影片，要在 `-ImportDir` 底下。預設的 `media\cat-demo.mp4` 是貓咪影片前 15 秒轉 H.264（約 8.6 MB），換裝置不用另外準備素材 |
| `-PlaySeconds` | `4` | 播放幾秒後停止 |
| `-IndexName` | `貓咪自拍影片` | 這次**新建**的索引集名稱，也當匯入的分類。已存在就拒絕執行（不覆蓋你既有的索引集） |
| `-NoteTitle` | `AI 自動化展示` | 展示便利貼的標題 |
| `-NoCleanup` | 關 | 跑完不清資料。**保留的話下次啟動桌面版會再冒出兩個懸浮視窗** |
| `-KeepAppOnFailure` | 關 | 中途失敗時讓桌面版留著開著、不清理（除錯用）。預設失敗也會自動收尾 |

需要：Windows PowerShell 5.1、Node.js（`npm start` 開桌面版）、Python 3（清理用）。桌面版必須是**關著**的。

## 執行時要知道的事

- **滑鼠與鍵盤會被接管約 4 分鐘，請不要碰。** 腳本用 `SetCursorPos`／`mouse_event`／`SendInput` 真的在操作。
- **會動到你的真實資料**：在「生活」分頁新增一張便利貼、在 `indexes/` 新建一個索引集並匯入資料夾。跑完預設**自動清掉**（見下），
  清理只動「這次產生、而且精確比對得到」的東西，比對不到就中止。
- **用除錯埠啟動**：桌面版是用 `npm start -- --remote-debugging-port=9333` 開的（不是 `.bat`），只綁本機、程式關掉就消失。
- **介面記憶會還原**：桌面版把「上次選的索引集」「檔案瀏覽器上次的位置」「上次的分頁（生活／研究生）」存在網頁的 localStorage，
  展示會改到它們。腳本跑之前先記下兩面牆的內容，結束前用除錯埠寫回去並驗證（**這是非畫面上的動作**，不是用滑鼠點的）。
  實測前後逐項比對完全一致。
- **中途失敗也會收尾**：任何一步失敗，腳本會先存一張失敗當下的整螢幕截圖並記錄對話框狀態（`out/shots/failure.png`、`out/run.log`），
  再還原介面記憶、用不靠滑鼠的方式正常關掉桌面版、清掉資料，最後以結束碼 1 結束。
- **打字會讀回確認**：SendInput 偶發會吃掉一個字元（實際發生過：標題少了最後一個「示」），所以每個輸入欄位打完都讀回內容比對，
  不一致就全選重打，最多 3 次。
- 截圖存在 `demo/out/shots/`（`.gitignore` 已排除）。**截圖是整個螢幕**，會拍到桌面上其他視窗，要分享前先檢查。

## 清理（`cleanup.py`）

`run.ps1` 結束後自動呼叫；也可單獨跑（桌面版要關著）：

```powershell
python wallpaper-app\demo\cleanup.py --title 'AI 自動化展示' --index 貓咪自拍影片 `
  --import-dir "$env:USERPROFILE\Documents\桌面牆展示素材" --restore-wall sticky `
  --since ([DateTimeOffset]::Now.AddMinutes(-10).ToUnixTimeSeconds())   # 只清這個時間之後新增的（必填）
```

會做的事：移除「這次執行期間新增、且帶展示特徵（完整標題／標籤「展示」／內文開頭句）」的便利貼（垃圾桶不動；不只認完整標題，
因為打字掉字時標題會殘缺）、刪掉這次產生的歷史快照、刪掉索引集（**只在裡面所有資料列
都落在 `--import-dir` 底下時才刪**）、移除桌面版設定裡的兩個懸浮視窗紀錄並把 `wall` 還原。動手前先備份到 `demo/out/backup/`。
用 Python 而不是 PowerShell，是因為這兩個 JSON 要「原樣寫回」，PowerShell 5.1 的 `ConvertTo-Json` 會整份重新排版；
腳本會先驗證「讀進來再寫出去」與原檔位元組一致才動手。

## 檔案

| 檔案 | 用途 |
|---|---|
| `run.ps1` | 整段流程；每一步記時間、用程式驗證結果（檔案有寫入、視窗有出現、影片實際播了幾秒…），最後印出警告清單 |
| `lib.ps1` | 底層：平滑移動滑鼠、點擊、拖曳、輸入 Unicode 文字、組合鍵、截圖、列出桌面牆視窗 |
| `cdp.ps1` | 透過除錯埠查詢「某個按鈕現在在螢幕的哪裡」（只讀位置），並等元素出現 |
| `cleanup.py` | 清掉這次新增的資料 |

## 這是「重播」，不是「AI 自主操作」——請照實說明

這支腳本的價值是**可重複、可錄影、跑得快**，但**不能拿來證明「AI 能即時看懂畫面自己操作電腦」**：

- 它知道每個按鈕的名稱與選擇器（事先讀過原始碼、走過一遍），並且是走網頁的**側門**讀 DOM 位置，**不是看螢幕畫面**。
- 遇到沒預料到的畫面它只會失敗停下，不會像看著螢幕的 AI 那樣判斷、修正。
- 真正「自主」的部分是**寫出這支腳本之前**的探索：對一個不熟的畫面，靠截圖一步步認出按鈕、避開刪除鈕、
  誤點後自己發現並退回。腳本只是把探索結果固化下來。

對外展示時建議兩者分開講：「AI 先自己摸索出流程」＋「再把流程變成一鍵重播」。

## 節奏（符合人眼的反應）

滑鼠每次移動 0.35 秒 → 點擊前停 0.13 秒 → 按 → 停 0.22 秒；重點畫面（便利貼新增成功、影片預覽出現、掃描結果）停 0.5～0.8 秒；
打字每字 25～30 ms（比真人打字快，但畫面上仍看得清楚）。要放慢改 `run.ps1` 裡的 `Hold` 與 `Click-Human`（`cdp.ps1`）的數字。

## 疑難排解／踩過的坑

- **`.ps1` 一定要存成 UTF-8 with BOM**：Windows PowerShell 5.1 讀沒有 BOM 的檔案會當成 ANSI，中文全部亂碼、整支解析失敗
  （跟 `../rebuild-if-stale.ps1` 的說明同一個坑）。改完存檔請保留 BOM。
- **PowerShell 5.1 的 `Invoke-RestMethod` 會把 JSON 陣列當成「一個物件」**，要用 `foreach` 展開（`cdp.ps1` 的 `Cdp-Targets`）。
- **HEVC（H.265）影片**：桌面版（Electron）是否能播取決於這台電腦的硬體／系統解碼器。腳本會把實際播放秒數、`readyState`、
  `canPlayType` 寫進 log，播不出來會列在警告清單。
- 找不到元素會逾時並中止；預設會自動收尾（見上）。要留著現場除錯用 `-KeepAppOnFailure`，處理完手動用右上角 ✕ 關掉，再跑 `cleanup.py`（介面記憶不會自動還原）。
- **不要用「切換牆」的方式只讀資料**：桌面版會把「上次停在哪面牆」寫進 `settings.json` 的 `wall`。腳本用 `--restore-wall` 還原它；
  自己手動檢查時如果按過 `Shift+C`，記得切回原本那面牆再關閉，否則下次會開在另一面（腳本會因為找不到便利貼牆的分頁而逾時）。
- 這個工具環境（Claude Code）會把 PowerShell 命令裡的 `\d+`、`Remove-Item Env:` 誤判成要刪除的路徑而整個擋下；
  自己在終端機跑不會有這個問題。
