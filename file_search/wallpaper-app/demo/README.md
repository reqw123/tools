# 桌面牆「產品展示」腳本

用**真實的滑鼠與鍵盤**把桌面牆的一整段操作自動走一遍，約 1 分鐘，給人看「桌面版能做什麼」。

```
開啟離線牆 → 新增便利貼 → 拖出去懸浮 → 切到索引牆（Shift+C）→ 新增索引集 → 匯入資料夾
→ 預覽影片 → 讓它懸浮 → 手動拖拉視窗邊界擴大 → 播放 N 秒後停止 → 按右上角 ✕ 結束程式
```

## 用法

**最簡單：雙擊專案根目錄的 `啟動-桌面牆自動化展示.bat`**（顯示提醒、倒數 5 秒後開始；後面接的參數會原封不動傳給 `run.ps1`，
例如 `啟動-桌面牆自動化展示.bat -PlaySeconds 3 -NoCleanup`；設環境變數 `DEMO_NOWAIT=1` 可略過倒數與結尾的暫停）。
批次檔要存成 **UTF-8 無 BOM ＋ CRLF**（BOM 會讓 cmd 讀壞第一行），中文訊息要放在 `chcp 65001` 之後。

或直接呼叫 PowerShell：

```powershell
# 用預設參數（貓咪自拍影片資料夾、播 4 秒）
powershell -ExecutionPolicy Bypass -File wallpaper-app\demo\run.ps1

# 換素材／秒數／保留資料
powershell -ExecutionPolicy Bypass -File wallpaper-app\demo\run.ps1 `
  -ImportDir 'C:\Users\homec\Downloads\3d遊戲資源' -VideoFile '不穩定碎片集合體.mp4' `
  -PlaySeconds 3 -IndexName '3d遊戲資源' -NoCleanup
```

| 參數 | 預設 | 說明 |
|---|---|---|
| `-ImportDir` | `C:\Users\homec\OneDrive\圖片\貓咪\自行拍攝\影片` | 要匯入的資料夾。**必須在 下載／文件／家目錄 底下**（檔案瀏覽器的捷徑），腳本從最近的捷徑一層層點進去 |
| `-VideoFile` | `VID20260904143024.mp4` | 要預覽、懸浮、播放的影片，要在 `-ImportDir` 底下 |
| `-PlaySeconds` | `4` | 播放幾秒後停止 |
| `-IndexName` | `貓咪自拍影片` | 這次**新建**的索引集名稱，也當匯入的分類。已存在就拒絕執行（不覆蓋你既有的索引集） |
| `-NoteTitle` | `AI 自動化展示` | 展示便利貼的標題 |
| `-NoCleanup` | 關 | 跑完不清資料。**保留的話下次啟動桌面版會再冒出兩個懸浮視窗** |
| `-KeepAppOnFailure` | 關 | 中途失敗時讓桌面版留著開著、不清理（除錯用）。預設失敗也會自動收尾 |

需要：Windows PowerShell 5.1、Node.js（`npm start` 開桌面版）、Python 3（清理用）。桌面版必須是**關著**的。

## 執行時要知道的事

- **滑鼠與鍵盤會被接管約一分鐘，請不要碰。** 腳本用 `SetCursorPos`／`mouse_event`／`SendInput` 真的在操作。
- **會動到你的真實資料**：在「生活」分頁新增一張便利貼、在 `indexes/` 新建一個索引集並匯入資料夾。跑完預設**自動清掉**（見下），
  清理只動「這次產生、而且精確比對得到」的東西，比對不到就中止。
- **用除錯埠啟動**：桌面版是用 `npm start -- --remote-debugging-port=9333` 開的（不是 `.bat`），只綁本機、程式關掉就消失。
- **介面記憶會還原**：桌面版把「上次選的索引集」「檔案瀏覽器上次的位置」「上次的分頁（生活／研究生）」存在網頁的 localStorage，
  展示會改到它們。腳本跑之前先記下兩面牆的內容，結束前用除錯埠寫回去並驗證（**這是非畫面上的動作**，不是用滑鼠點的）。
  實測前後逐項比對完全一致。
- **中途失敗也會收尾**：任何一步失敗，腳本會先存一張失敗當下的整螢幕截圖並記錄對話框狀態（`out/shots/failure.png`、`out/run.log`），
  再還原介面記憶、用不靠滑鼠的方式正常關掉桌面版、清掉資料，最後以結束碼 1 結束。
- **打字會讀回確認**：SendInput 偶發會吃掉一個字元（實際發生過：標題少了最後一個「示」），所以每個輸入欄位打完都讀回內容比對，
  不一致就全選重打，最多 3 次。
- 截圖存在 `demo/out/shots/`（`.gitignore` 已排除）。**截圖是整個螢幕**，會拍到桌面上其他視窗，要分享前先檢查。

## 清理（`cleanup.py`）

`run.ps1` 結束後自動呼叫；也可單獨跑（桌面版要關著）：

```powershell
python wallpaper-app\demo\cleanup.py --title 'AI 自動化展示' --index 貓咪自拍影片 `
  --import-dir 'C:\Users\homec\OneDrive\圖片\貓咪\自行拍攝\影片' --restore-wall sticky `
  --since ([DateTimeOffset]::Now.AddMinutes(-10).ToUnixTimeSeconds())   # 只清這個時間之後新增的（必填）
```

會做的事：移除「這次執行期間新增、且帶展示特徵（完整標題／標籤「展示」／內文開頭句）」的便利貼（垃圾桶不動；不只認完整標題，
因為打字掉字時標題會殘缺）、刪掉這次產生的歷史快照、刪掉索引集（**只在裡面所有資料列
都落在 `--import-dir` 底下時才刪**）、移除桌面版設定裡的兩個懸浮視窗紀錄並把 `wall` 還原。動手前先備份到 `demo/out/backup/`。
用 Python 而不是 PowerShell，是因為這兩個 JSON 要「原樣寫回」，PowerShell 5.1 的 `ConvertTo-Json` 會整份重新排版；
腳本會先驗證「讀進來再寫出去」與原檔位元組一致才動手。

## 檔案

| 檔案 | 用途 |
|---|---|
| `run.ps1` | 整段流程；每一步記時間、用程式驗證結果（檔案有寫入、視窗有出現、影片實際播了幾秒…），最後印出警告清單 |
| `lib.ps1` | 底層：平滑移動滑鼠、點擊、拖曳、輸入 Unicode 文字、組合鍵、截圖、列出桌面牆視窗 |
| `cdp.ps1` | 透過除錯埠查詢「某個按鈕現在在螢幕的哪裡」（只讀位置），並等元素出現 |
| `cleanup.py` | 清掉這次新增的資料 |

## 這是「重播」，不是「AI 自主操作」——請照實說明

這支腳本的價值是**可重複、可錄影、跑得快**，但**不能拿來證明「AI 能即時看懂畫面自己操作電腦」**：

- 它知道每個按鈕的名稱與選擇器（事先讀過原始碼、走過一遍），並且是走網頁的**側門**讀 DOM 位置，**不是看螢幕畫面**。
- 遇到沒預料到的畫面它只會失敗停下，不會像看著螢幕的 AI 那樣判斷、修正。
- 真正「自主」的部分是**寫出這支腳本之前**的探索：對一個不熟的畫面，靠截圖一步步認出按鈕、避開刪除鈕、
  誤點後自己發現並退回。腳本只是把探索結果固化下來。

對外展示時建議兩者分開講：「AI 先自己摸索出流程」＋「再把流程變成一鍵重播」。

## 節奏（符合人眼的反應）

滑鼠每次移動 0.35 秒 → 點擊前停 0.13 秒 → 按 → 停 0.22 秒；重點畫面（便利貼新增成功、影片預覽出現、掃描結果）停 0.5～0.8 秒；
打字每字 25～30 ms（比真人打字快，但畫面上仍看得清楚）。要放慢改 `run.ps1` 裡的 `Hold` 與 `Click-Human`（`cdp.ps1`）的數字。

## 疑難排解／踩過的坑

- **`.ps1` 一定要存成 UTF-8 with BOM**：Windows PowerShell 5.1 讀沒有 BOM 的檔案會當成 ANSI，中文全部亂碼、整支解析失敗
  （跟 `../rebuild-if-stale.ps1` 的說明同一個坑）。改完存檔請保留 BOM。
- **PowerShell 5.1 的 `Invoke-RestMethod` 會把 JSON 陣列當成「一個物件」**，要用 `foreach` 展開（`cdp.ps1` 的 `Cdp-Targets`）。
- **HEVC（H.265）影片**：桌面版（Electron）是否能播取決於這台電腦的硬體／系統解碼器。腳本會把實際播放秒數、`readyState`、
  `canPlayType` 寫進 log，播不出來會列在警告清單。
- 找不到元素會逾時並中止；預設會自動收尾（見上）。要留著現場除錯用 `-KeepAppOnFailure`，處理完手動用右上角 ✕ 關掉，再跑 `cleanup.py`（介面記憶不會自動還原）。
- **不要用「切換牆」的方式只讀資料**：桌面版會把「上次停在哪面牆」寫進 `settings.json` 的 `wall`。腳本用 `--restore-wall` 還原它；
  自己手動檢查時如果按過 `Shift+C`，記得切回原本那面牆再關閉，否則下次會開在另一面（腳本會因為找不到便利貼牆的分頁而逾時）。
- 這個工具環境（Claude Code）會把 PowerShell 命令裡的 `\d+`、`Remove-Item Env:` 誤判成要刪除的路徑而整個擋下；
  自己在終端機跑不會有這個問題。
