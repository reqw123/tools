## 1. 這是什麼

一個**以手動維護的 Markdown 表格為核心**的檔案索引搜尋工具。適合把散落在
整台電腦各處的檔案（論文、截圖、教學筆記、素材……）用一句話說明 + 分類
記下來，之後靠關鍵字快速找回來、直接開啟。

核心原則：

- **程式不會在背景自行掃描硬碟。** 只有在你按下「匯入資料夾」「找出未收錄
  檔案」「更新內容快取」「重複偵測」時，才會去讀取你指定的檔案。
- **索引來源是 `indexes/` 資料夾底下的 `.md` 檔案**，每個 `.md` 是一份獨立的
  「索引集」，格式規定寫在每份檔案開頭。你可以用純文字編輯器手動維護，也可以
  用 App 的按鈕自動附加。
- **任何刪除／編輯操作都只動索引紀錄本身**（`indexes/` 底下的 `.md` 與附屬
  JSON），**絕不刪除或修改硬碟上真正的原始檔案**。詳見
  [§19 重要保證](#19-重要保證)。

## 2. 啟動方式與選用套件

### 啟動

```
python file_search.py
```

實際程式碼在 `file_search_app/` 套件底下（UI／Service／Repository 分層），
`file_search.py` 只是相容啟動入口。也有 PyInstaller 打包成單一 `.exe` 的
設定（見 `packaging/`）；打包版會把使用者資料（`indexes/`）放在 `.exe`
旁邊。

### 核心相依

- **Python 3** + 內建的 **tkinter**（GUI）。
- AI 功能只用 Python 標準函式庫的 `urllib` 呼叫 HTTP，**不需要**安裝
  `openai` 之類的 SDK。

### 選用套件（沒裝也能跑，只是對應功能會降級或隱藏）

| 套件 / 外部程式 | 缺了會怎樣 |
|---|---|
| `tkinterdnd2` | 不能把檔案拖曳進清單新增（仍可用「新增檔案...」按鈕）。工具列會顯示提示。 |
| `Pillow` | 圖片不顯示縮圖（改顯示圖示）；AI 也無法分析圖片。 |
| `pypdf`（或舊名 `PyPDF2`） | PDF 無法預覽內文、內文不進全文搜尋（仍可「開啟檔案」）。 |
| `py7zr` | `.7z` 壓縮檔無法列出內容檔名。`.zip` 不受影響（用內建 `zipfile`）。 |
| `pywin32` + 已安裝的 **Microsoft Office** | 舊版二進位 `.doc` / `.ppt` / `.xls` 無法擷取內文（`.docx` / `.pptx` / `.xlsx` 用內建解析，不受影響）。 |
| **VLC 應用程式** + `python-vlc` | 無法在預覽區內建播放器播放 MP3／MP4（改顯示圖示＋提示，仍可「開啟檔案」用系統播放器）。 |
| `faster-whisper` | 無法把音訊／影片的語音轉成文字。 |
| **Ollama** + `ollama pull bge-m3` | 便利貼「🧠 語意搜尋」不能用（開關會提示、自動退回一般關鍵字搜尋）。見 [§14](#14-便利貼)。 |

Office 舊格式與語音辨識都在**獨立子行程**執行（`_legacy_office_worker.py` /
`_transcription_worker.py`），避免它們的原生層崩潰時把整個 App 拖死。

## 3. 主視窗版面

由上到下：

1. **標題列** — 「📁 檔案快速搜尋」＋右上角的**索引集下拉選單**與
   「➕ 新增索引集」「🗑️ 刪除索引集」。
2. **❓ 功能介紹／使用說明** — 收合時是一條窄提示條，點一下往下拉開一大塊
   說明抽屜。見 [§15](#15-功能介紹面板)。
3. **搜尋列** — 🔍 搜尋框 ＋ 淡藍色篩選容器（分類、資料夾下拉）＋
   「🔬 選檔案問 AI...」。
4. **索引管理列** — 新增檔案／匯入資料夾／編輯索引檔案／重新載入索引／
   ⚠️ 清除失效項目／🗑️ 批次刪除。
5. **進階工具列** — 🔄 更新內容快取／🔎 找出未收錄檔案／🧬 重複偵測／
   ✍️ 批次補說明／🤖 AI 批次說明／（旁邊有一個會呼吸的橙色泡泡指向
   「⚙️ AI 設定」）。
6. **主體區**（可用拉桿調整各區寬度）：
   - 左側：**便利貼面板**（常駐、可收合，見 [§14](#14-便利貼)）
   - 中間：**索引清單**（Treeview）
   - 右側：**預覽區**（見 [§10](#10-預覽區)）
7. **選取項目操作列** — 📂 開啟檔案／🗂️ 顯示於檔案總管／📋 複製路徑／
   ✏️ 編輯所選列／⤒ 第一筆／⤓ 最後一筆。
8. **狀態列** — 索引項目總數 ＋ 目前搜尋／篩選結果的文字說明。

### 清單欄位

| 欄位 | 說明 |
|---|---|
| 序號 | 每份索引集從 1 開始編號；搜尋或篩選後**不會**重新編號。批次刪除視窗用相同流水號。 |
| （圖示） | 依副檔名顯示類型圖示，純粹方便掃視；找不到檔案時顯示 ⚠️。 |
| 檔名 | 路徑的最後一段。 |
| 分類 | 索引表格的分類欄。 |
| 說明 | 索引表格的說明欄（關鍵字都寫這裡）。 |
| 路徑 | 寫在索引檔案裡的原始路徑字串。 |
| 來源索引集 | **只在「全部索引」模式**顯示，標出每筆屬於哪一份 `.md`。 |
| 加入時間 | 透過 App 新增／拖曳／匯入的項目會記錄（例如 `8/18 08:00`）；手動編輯 `.md` 加進去的舊項目顯示「—」。 |

指向的檔案目前找不到時（可能已搬移或刪除），該列會以**紅字**顯示。

### 版面調整

- 清單與預覽之間、便利貼與清單之間都有 **↔ 拉桿**，左右拖曳調整寬度。
- 視窗本身縮放時，各區寬度會自動重新分配，不會把某一塊擠到看不見。
- 便利貼面板寬度**每次啟動回到預設**，只有「上次是展開還是收合」會記住。

## 4. 索引集管理

`indexes/` 底下每個 `.md` 檔案 = 一份獨立索引集。程式啟動時若完全沒有任何
`.md`，會自動建立一份格式正確的空白 `file_index.md`。

| 操作 | 位置 | 說明 |
|---|---|---|
| **切換索引集** | 右上角下拉選單 | 選某一份 `.md`，或選「🗂 全部索引（跨檔案）」同時檢視／搜尋全部。 |
| **➕ 新增索引集...** | 標題列 | 在 `indexes/` 底下建立新的空白 `.md`，取名後自動切過去。檔名不能含 Windows 非法字元、不能與現有檔案撞名。 |
| **🗑️ 刪除索引集** | 標題列 | 刪除目前選取的索引集，連同它的內容快取與加入時間紀錄。會先顯示名稱與筆數要求確認。**不刪實體檔案。** 「全部索引」模式下不能刪。 |
| **編輯索引檔案** | 索引管理列 | 用系統預設程式（優先 VS Code，找不到退回記事本）開啟目前索引集的 `.md`，手動編輯格式或內容。 |
| **重新載入索引** | 索引管理列 | `.md` 在外部被改過時，重新讀取，不用重開 App。 |

### 「全部索引」聚合模式

- 同時檢視／搜尋全部索引集；清單多一欄「來源索引集」。
- 序號依合併順序連續編號。
- **不能直接新增／匯入資料**（因為沒有單一目標檔案），會跳警告要求先切回
  某一份單一索引集。
- 「清除失效項目」「批次刪除」「更新內容快取」「重複偵測」在這個模式下會
  對**全部**索引集生效。

### 索引 `.md` 表格格式

```
| `完整路徑\檔名.副檔名` | 分類 | 一句話說明或關鍵字 |
```

- 路徑用單一反引號包住（路徑內含反引號時程式會自動用更長的圍欄）。
- 分類欄、說明欄都可以留空，但**不能含 `|` 符號**（會被誤判成表格分隔線）；
  要表達「或」請用「／」。
- 分類欄留空的項目在篩選選單裡歸類為「未分類」。
- 一行只能收錄一個檔案；同一檔案要多個關鍵字都搜得到，就把關鍵字都寫進
  說明欄（搜尋比對說明欄全文）。
- 格式不符的列程式會**直接跳過、不報錯**，但那筆資料就搜不到。
- 表格裡列的先後順序不影響搜尋，純粹是閱讀順序。

## 5. 搜尋與篩選

### 🔍 搜尋框

輸入關鍵字**即時篩選**，全部轉小寫比對。比對範圍：

- 序號
- 檔名
- 分類
- 說明
- 完整路徑
- 加入時間（顯示字串，例如 `8/18 08:00`）
- **內容快取的擷取文字**（只有跑過「更新內容快取」的檔案才有 — 見 [§8](#8-內容快取與全文搜尋)）

`Ctrl+F` 跳到搜尋框並選取現有文字；`Esc` 清空搜尋框。

### 分類（下拉選單）

位於淺藍色篩選容器中，只顯示指定分類。選項依目前索引實際出現過的分類自動
組成，外加（有需要時）「未分類」。

### 資料夾（下拉選單）

位於淺藍色篩選容器中，只顯示指定父資料夾底下的項目。選項是目前索引裡所有
項目的父資料夾清單。

分類、資料夾、關鍵字三者可以**疊加**使用。分類／資料夾的選擇會跨次啟動
記住。

### ⤒ 第一筆／⤓ 最後一筆

直接選取並捲動到目前結果的第一筆或最後一筆。鍵盤 `Home` / `End` /
`Ctrl+Home` / `Ctrl+End` 也可以。

## 6. 把檔案加進索引

所有新增方式最後都寫成同一種表格格式附加到 `.md` 表格最後一行，並記錄加入
時間。已收錄過（路徑正規化後相同）、不存在、或選到資料夾的項目會自動排除
並回報筆數。

| 方式 | 說明 |
|---|---|
| **拖曳檔案** | 把一個或多個檔案拖進清單。與「新增檔案...」共用相同驗證與逐筆輸入流程。拖入資料夾會提示改用「匯入資料夾...」。（需 `tkinterdnd2`） |
| **新增檔案...** | 檔案選擇對話框，可複選；逐筆填分類／說明後加入。 |
| **匯入資料夾...** | 選一整個資料夾，可勾選是否包含子資料夾、依副檔名類型（文件／簡報／試算表／PDF／文字／圖片／音樂／影片／壓縮檔）用按鈕篩選，整批加入（整批同一個分類，說明欄留空）。已收錄過的自動略過。 |
| **🔎 找出未收錄檔案...** | 掃描「常用資料夾清單」（可在對話框裡管理／臨時新增），列出還沒被**任何**索引集收錄的檔案，勾選後整批加入指定的索引集。目標索引、分類與收錄按鈕固定在視窗底部。 |

### 大量掃描的兩道防線

「匯入資料夾」「找出未收錄檔案」都是遞迴列出整個資料夾。若不小心選到磁碟機
根目錄或有幾十萬檔案的資料夾：

- 掃描過程中超過 **1,000 筆**（軟上限）會先暫停，跳出對話框問要不要繼續看
  下去。不管答案是哪個，**這次掃描結果都不能直接匯入／加入索引**，只能瀏覽
  ／確認筆數。
- 掃到 **500,000 筆**（硬上限）一定強制停止。

掃描完的結果除了總筆數，還會依九大類別分別顯示各有幾筆。

## 7. 編輯與刪除

> 全部都只改索引紀錄，**不刪硬碟上的實體檔案**。

| 操作 | 位置 | 說明 |
|---|---|---|
| **✏️ 編輯所選列** | 選取項目操作列 | 改這一筆的分類／說明。用資料列序號（`row_index`）精確定位，寫回它實際的來源索引檔案 — 就算同一份索引裡有其他路徑完全相同的列也不會被牽連，也不影響它在表格裡的位置。 |
| **Delete 刪除所選列** | 鍵盤 / 選取項目操作列 | 選取列會以藍色標記；按 `Delete` 後需再次確認。只移除該列，同路徑的其他列保留。 |
| **🗑️ 批次刪除...** | 索引管理列 | 開啟顯示原始流水號與項目名稱的清單，可用序號或名稱搜尋、勾選目前結果並批次移除。 |
| **⚠️ 清除失效項目** | 索引管理列 | 掃描目前檢視範圍的索引，把「指向的檔案已經不存在」的資料列整批移除。會先顯示筆數要求確認。 |

編輯或刪除時若索引檔案剛好被外部改過（找不到對應的列），會提示你先「重新
載入索引」再試。

## 8. 內容快取與全文搜尋

一般搜尋只比對索引表格本身的欄位（檔名／分類／說明／路徑…）。要能搜到
**檔案內文**，需要先建立「內容快取」。

### 🔄 更新內容快取

- **跨全部索引集**、手動觸發、在背景執行（有進度視窗）。
- 對每個索引項目做兩件事：
  1. **重新計算 SHA-256**（每次都重算，串流方式，大型影片也涵蓋）。
  2. **必要時重新擷取內文**：只有檔案的 mtime／大小／雜湊有變動時才重新
     讀取內文，沒變就沿用舊的。
- 擷取到的文字存進 `indexes/.cache/<索引檔名>.json`，上限每檔 5,000 字元。
- 更新完，搜尋框就能比對到這些檔案的內文了。
- 順便清掉已經不在索引裡的舊快取項目。

支援擷取內文的格式見 [§17](#17-支援的檔案格式)。擷取不到內文的類型（純圖片、
執行檔等）只會有 SHA-256、沒有可搜尋的文字。

## 9. 重複偵測（SHA-256）

### 🧬 重複偵測...

- **跨全部索引集**。
- 按下後會**先自動重新驗證全部檔案的 SHA-256**（沿用「更新內容快取」的
  背景流程），避免新加入或內容變更過的檔案沿用舊結果而漏判。
- 再依「檔案大小 ＋ SHA-256」分組，只列出真的有 2 筆以上完全相同的組。
- 每組自己選一筆保留，其餘只**移除索引列**，**不刪實體檔案**。

> 檔名相同 ≠ 內容相同；只要任何標籤、音訊資料或位元內容不同，SHA-256 就會
> 不同。

## 10. 預覽區

右側預覽區依副檔名／內容自動切換顯示模式：

| 模式 | 觸發 | 內容 |
|---|---|---|
| 圖片 | `.jpg .jpeg .png .gif .bmp .webp` | 縮圖，大小跟著預覽區寬度走（拉桿拉多寬圖就多大，上限約 640px）。需 `Pillow`。 |
| 文字 | 純文字類型、Office／PDF 等可擷取內文的類型、以及「內容看起來像文字」的任何檔案 | 可捲動的內文（讀開頭約 3,000 字元）。 |
| 影音播放器 | `.mp3 .wav .flac .m4a .mp4 .mov .avi .mkv .wmv` | 內建播放器，見 [§11](#11-影音播放)。需 VLC。 |
| 轉錄文字 | 在播放器按「📝 查看轉錄文字」 | 見 [§12](#12-音訊影片轉錄)。 |
| 圖示 | 找不到檔案、或此類型沒有內容預覽 | 大圖示 ＋ 一句提示（例如「按開啟檔案查看」、缺套件提示）。 |

### 文字預覽字級縮放

- `Ctrl` ＋ `＝` / `－` 放大縮小，`Ctrl+0` 還原預設。
- 滑鼠移到預覽文字上時 `Ctrl+滾輪` 也可以。
- 範圍 8–32pt。（跟 VS Code 同一套手感。）

> 這組縮放跟「功能介紹面板」的字級縮放共用同一組按鍵：功能介紹面板展開時
> 由它接手，收合時才輪到預覽區。

### 文字編碼

預覽會依序嘗試 BOM → UTF-16 特徵 → UTF-8 → 中文 Windows 常見 ANSI
（cp950／big5／cp936）判斷編碼，盡量避免亂碼。

## 11. 影音播放

選取 MP3／MP4 等媒體檔會直接在預覽區顯示內建播放器（需要系統裝了 VLC）。

### 控制列

| 元件 | 說明 |
|---|---|
| ▶ / ⏸ | 播放／暫停。 |
| ⏹ | 停止。 |
| ⛶ 大視窗 | 影片專用：開獨立視窗播放，畫面上限 1280×720，`Esc` 關閉。音樂檔此鍵停用。 |
| 時間 | `目前 / 總長`。 |
| ← → 方向鍵跳轉 N 秒 | 影片左右鍵一次倒退／快轉的秒數，可調（1–600 秒，預設 5 秒，跨次啟動記住）。 |
| 進度列 | 可拖曳。 |
| 音量列 | 可拖曳。 |

### 行為

- **瀏覽清單不會自動出聲** — 要按 ▶ 才播。
- 用方向鍵快速連續切換好幾個 mp3/mp4 時，播放器的重建會延遲一小段時間，
  避免密集重建在某些顯示卡組合下引發原生層資源競爭。
- 切換到別的項目或別的顯示模式時一律停止播放。

### 快捷鍵

清單上選取媒體檔後：

- **空白鍵** — 播放／暫停（這是「現在就播」，不走延遲）。
- **影片左右鍵** — 倒退／快轉（秒數由上面的欄位決定）。
- 沒載入影片時，左右鍵保留清單原本的導覽行為。

## 12. 音訊／影片轉錄

播放器下方有「🎙️ 轉錄」按鈕（需安裝 `faster-whisper`；沒裝會改顯示一行
灰字提示）。

- 用**本機**語音辨識（faster-whisper，固定 `small` 模型、固定辨識中文）把
  MP3／MP4 的語音轉成文字。**純本機處理，內容不會離開這台電腦**，不需要
  任何 API Key。
- 第一次使用會另外下載模型，可能要等一段時間；轉錄過程有進度百分比，可按
  「取消」中止。
- 轉好的文字**寫進內容快取**，所以之後在搜尋框也能搜到「影片裡說了什麼」。
- 轉好後按鈕變成「🔁 重新轉錄」，並多一顆「📝 查看轉錄文字」可切換到閱讀
  模式（同樣可 `Ctrl+滾輪` 縮放字級），「🎬 回到播放器」切回去。
- 純音樂、環境音、沒有旁白的螢幕錄影轉出來會是空的，會提示「沒有辨識出
  任何文字」。
- 轉錄在獨立子行程執行，就算語音辨識的原生函式庫在這台機器上崩潰，也只有
  那個子行程死掉，不會拖垮整個 App。

## 13. AI 功能

AI 功能是**選用**的，需要先設定 Provider。全部 AI 功能共用同一份設定與同一個
「累計呼叫次數」計數器。

### ⚙️ AI 設定

AI 沒有獨立的設定按鈕 — 要先開「🤖 AI 批次說明...」，視窗**上方**才有
「⚙️ AI 設定...」。（進階工具列上那顆會呼吸的橙色泡泡就是在指這裡。）

可選兩種 Provider：

| Provider | 說明 |
|---|---|
| **Ollama（🖥️ 就在這台電腦）** | 本機語言模型，內容不離開這台電腦，不計費。需要自己先跑 Ollama。 |
| **Ollama（🌐 區網裡的另一台電腦）** | 指到區網內另一台跑 Ollama 的機器（例如 `http://192.168.0.171:11434`）。內容會透過區域網路傳到那台電腦，但不上網際網路、不計費。那台機器需以 `OLLAMA_HOST=0.0.0.0` 啟動並開放 11434 埠。 |
| **OpenAI（雲端）** | 需要 API Key。**內容會離開這台電腦，每次呼叫可能計費。** 也相容其他 OpenAI 相容端點（換 base_url）。 |

設定視窗細節：

- 「在哪裡執行」用兩顆單選鈕切換本機／區網，非技術使用者不用知道
  `localhost` 是什麼；改壞了點回「就在這台電腦」就能復原。
- 進階模式可填完整 URL（自訂埠、https）。
- 模型名稱是**可編輯的下拉選單**，會去抓那台 Ollama 已安裝的模型清單，也
  可以自己打（未 `pull` 的模型或舊版 Ollama 不會變成死路）。
- 「測試連線」除了「連得上／連不上」，還會警告「連得上但這個模型不能用」
  （模型不在清單裡、或模型是純文字模型卻要拿來看圖）。

### 送出前的確認與用量提示

**每一個 AI 功能、每一個 Provider（包含本機 Ollama）**，送出前都會跳視窗
明確寫出：

- 送去哪個 Provider／模型／位址、內容會不會離開這台電腦。
- 這次送出的內容量（粗略字元數，標明「非精確 token 數」）。
- 這是全部 AI 功能累計第幾次呼叫。

> 這裡不計算實際金額 — 那需要各家 Provider 的定價表，這支 App 沒有這個
> 資料來源。所有數字都是粗估，實際費用／額度以你的 Provider 帳單為準。

### 🔬 選檔案問 AI...

（搜尋列，資料夾篩選正下方。）

- 跟索引**完全無關**的即席分析：自選任何一個檔案，送目前設定的 Provider
  分析，回覆只顯示出來供你查看、可複製，**不會寫進任何索引**。
- 文字類送擷取到的內文；圖片送縮小過的縮圖給視覺模型；音訊／影片先本機
  轉錄再送文字。

### 🤖 AI 批次說明...

（進階工具列。跟「✍️ 批次補說明」不同 — 那個是純本機、直接拿內文前段當
建議，不呼叫 AI。）

- 針對**目前檢視範圍內「說明欄是空的」**項目。
- 先開一個可搜尋、可勾選的清單（**預設全部不勾選**），你自己決定要花時間／
  額度送哪幾筆。
- 送出後在背景逐筆呼叫 AI；跑完的建議進**審核視窗**（每頁 8 筆，可編輯、
  可調字級），逐筆確認才寫進索引。
- 圖片項目改用視覺模型分析；音訊／影片先轉錄再摘要。

### ✍️ 批次補說明...（對照組，不是 AI）

- 純本機、瞬間完成、不需要任何設定。
- 在背景擷取「說明欄是空的」項目的內文，直接拿內文開頭幾行當建議說明。
- 一樣進審核視窗逐筆確認。

見 [§14](#14-便利貼)。

## 14. 便利貼

左側常駐面板，用來記常用指令、網站、備忘 — 跟索引項目完全無關、全域共用、
不綁定任何索引集。資料存在 `indexes/.sticky_notes.json`。

### 面板開關

- 快捷鍵 `Ctrl+Shift+N` 隨時開關。
- 面板上的「◀」按鈕可以收合；收合後左邊界留一個「▶」小把手，點一下重新
  展開。
- **收合狀態跨次啟動記住**（寬度不記住，每次啟動回預設）。

### 卡片

- 每張卡片有標題、內容（可多行，例如一串指令步驟，超過範圍可捲動）、標籤
  （可留空）。
- **標籤相同的便利貼自動套用同一個顏色**（色相取自標籤字串的 MD5 雜湊，
  跨次啟動穩定），不用手動選色。沒有標籤的用中性灰。
- **單擊卡片** → 直接把內容複製到剪貼簿（右下角彈出「已複製」提示）。
- **右鍵卡片** → 複製／編輯／刪除。
- **空白處右鍵** → 新增便利貼。

### 標題列按鈕

| 按鈕 | 說明 |
|---|---|
| ➕ | 新增便利貼。 |
| 📤 | 把**目前篩選出的清單**匯出成 Markdown（標題／標籤／內容各自成段，內容放進程式碼區塊保留原始換行）。 |
| 🗑 | 批次刪除：可搜尋、可勾選的清單，預設全部不勾，需再次確認。 |
| 📝 | 用文字編輯器直接開啟底層的 `.sticky_notes.json`（進階用途，原始 JSON 格式，手動編輯請小心別打壞結構）。 |
| ◀ | 收合面板。 |

### 搜尋與篩選

- **搜尋框** — 關鍵字比對標題／內容／標籤（在搜尋框直接打標籤名稱或一部分
  就能找到該標籤的便利貼）。
- **標籤下拉選單** — 精確只顯示選定的那個標籤。
- 兩者可疊加。

### 🤖 AI 搜尋

搜尋框旁的 🤖 按鈕。可以問**一般語句**，不用打精確關鍵字，例如：

- 「每日必做有哪些事項」（統整內容回答）
- 「youtube 相關的有幾個」（回答數字）
- 「目前有哪些分類」（列出全部標籤）

行為：

- 送出前**先套用目前的標籤篩選**（呼應畫面上看得到的範圍，不是無腦送全部）。
- 送出前一律跳確認視窗（本機、雲端都會）；便利貼超過 30 則會額外提醒先用
  標籤篩選縮小範圍。
- AI 的完整自然語言答案會跳視窗顯示，同時卡片清單篩選成相關的那幾則。
- AI 搜尋結果是**暫時覆蓋**一般關鍵字搜尋的狀態：只要你改動搜尋框文字，
  就自動失效退回一般比對，不需要另外一顆「清除」按鈕。
- AI 會**推斷你的意圖**（例如「我口渴了」→ 找飲料類），回傳的便利貼依
  相關程度由高到低排序。實際效果看那台 Ollama 用的模型。

### 🧠 語意搜尋（🌱，notes-web / 桌面牆）

搜尋框旁的「語意」開關（notes-web 的 🌱、桌面面板的「🧠 語意搜尋」勾選框）。
用本機 Ollama 的 **embedding 模型**把查詢句和每則便利貼都轉成向量、依相似度
排序——字面對不上但**意思相近**的也找得到，而且**不計費、不耗 token、內容
不離開這台電腦**。

- **要先下載一個 embedding 模型**（跟聊天模型不同）：
  ```
  ollama pull bge-m3
  ```
  `bge-m3`（BAAI，約 1.2GB）多語言、中文效果好，是預設。純英文環境想省
  空間可改用 `nomic-embed-text`（約 274MB，中文較弱）——在 notes-web
  「全域設定 → 外觀 → 語意搜尋的嵌入模型」填模型名稱。
- 位址沿用「AI 請求」那頁的 Ollama 設定（本機或區網主機都行）。
- 第一次搜尋會把全部便利貼算成向量（幾秒），之後只算查詢句；向量有快取
  （`indexes/.sticky_notes_embeddings.json`），換模型會整份重算。
- 跟 🤖 AI 搜尋**互斥**（兩種都是「換一種找法」）。跟語意夠接近的都沒有時
  會提示「換個說法或關掉語意」。
- **適合**：「同一個主題、不同用詞」「某分類底下有什麼」。
  **不適合**：需要多步推理的跳躍——那種用 🤖 AI 搜尋。

## 17. 支援的檔案格式

### 內文擷取（預覽 ＋ 全文搜尋 ＋ AI 摘要共用同一套解析）

| 類型 | 副檔名 | 方式 / 需求 |
|---|---|---|
| 純文字（快速通道） | `.txt .md .csv .log .json .ini .yaml .yml .py` | 直接讀，內建。 |
| 其他「看起來像文字」的檔案 | 任何副檔名（`.html .js .css .sql .h ...`） | 讀開頭一段判斷內容像不像文字，像就當文字讀。不用逐一加白名單。 |
| Word / PowerPoint / Excel（新版） | `.docx .pptx .xlsx` | 用 `zipfile` 挖出裡面的 XML 自己解析，**內建、不需套件**。 |
| Word / PowerPoint / Excel（舊版二進位） | `.doc .ppt .xls` | Office COM 自動化子行程，需 Windows + Office + `pywin32`。 |
| PDF | `.pdf` | 需 `pypdf` 或 `PyPDF2`（讀前 5 頁）。加密 PDF 略過。 |
| ZIP | `.zip` | 只列出內含檔名（不解開內容），內建。 |
| 7-Zip | `.7z` | 只列出內含檔名，需 `py7zr`。 |

真正的二進位格式（圖片／音訊／影片／`.exe` `.dll` `.rar` `.rtf` 等）不會被
硬解成亂碼，會直接跳過。

### 圖示對照（清單裡的類型圖示）

📄 文件（doc/docx/rtf）｜📊 簡報（ppt/pptx）｜📈 試算表（xls/xlsx/csv）｜
📕 PDF｜📃 純文字（txt/md）｜🖼️ 圖片｜🎵 音樂（mp3/wav/flac/m4a）｜
🎬 影片（mp4/mov/avi/mkv/wmv）｜🗜️ 壓縮檔（zip/rar/7z）｜📁 其他

### 圖片

`.jpg .jpeg .png .gif .bmp .webp` — 縮圖需 `Pillow`；送 AI 前會縮小、統一
轉 JPEG。

### 影音

音訊 `.mp3 .wav .flac .m4a`、影片 `.mp4 .mov .avi .mkv .wmv` — 內建播放需
VLC；轉錄需 `faster-whisper`。

## 18. 資料檔案與存放位置

全部在 `indexes/` 資料夾底下（打包成 `.exe` 時 = `.exe` 旁邊）：

| 檔案 | 內容 |
|---|---|
| `*.md` | 索引集本身（手動可讀可編輯的 Markdown 表格）。 |
| `.cache/<索引檔名>.json` | 內容快取：每筆的 `mtime / size / SHA-256 / 擷取文字`。全文搜尋與重複偵測共用。 |
| `.added_times.json` | 每筆項目的加入時間。 |
| `known_folders.txt` | 「找出未收錄檔案」的常用資料夾清單，每行一個路徑。 |
| `.sticky_notes.json` | 便利貼資料。 |
| `.ai_settings.json` | AI Provider 設定（provider、OpenAI 的 key/model/base_url、Ollama 的 base_url/model）。 |
| `.ai_usage.json` | 全部 AI 功能累計呼叫次數。 |
| `.app_prefs.json` | 影片跳轉秒數、功能介紹面板字級增減量。 |

刪除某個索引集時，會一併清掉它的 `.cache/*.json` 與 `.added_times.json`
裡對應的那一份，不留孤兒資料。

## 19. 重要保證

> **這支程式的任何刪除／編輯操作，影響範圍都只限於 `indexes/` 底下自己的
> 索引紀錄與便利貼資料本身，絕對不會刪除或修改硬碟上真正的原始檔案。**

具體來說：

- 「刪除索引集」「Delete 刪除所選列」「批次刪除」「清除失效項目」「重複
  偵測移除重複」 — 全部只改 `.md` 索引檔案的資料列。
- 每個確認視窗都會明講「不會刪除硬碟上的實體檔案」。
- 程式不會在背景掃描硬碟；只在你按下明確的按鈕時才去讀取指定的檔案，而且
  只有讀取，沒有寫入或刪除。

唯一會被程式建立／覆寫的檔案，是 `indexes/` 底下它自己的索引與設定資料
（見 [§18](#18-資料檔案與存放位置)），全部用原子寫入（先寫暫存檔再置換）
避免寫到一半中斷造成損毀。
